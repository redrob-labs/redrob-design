# Совместная работа

Откройте файл приглашённым людям и редактируйте его вместе в реальном времени. Чтобы поделиться файлом, нужен вход в Redrob Cloud (Настройки, Cloud); всё остальное в Redrob Design работает без учётной записи.

## Как поделиться файлом

1. Нажмите **Поделиться** в правом верхнем углу, затем **Поделиться этим файлом**.
2. Пригласите людей по адресу почты и выберите права: **Может редактировать**, **Может комментировать** или **Может смотреть**. Человек без учётной записи получит файл, когда впервые войдёт с этим адресом.
3. **Копировать ссылку** даёт ссылку, которая открывается у тех, у кого есть доступ.

Файлы, которыми поделились с вами, показаны на главной странице в разделе **Доступные вам**.

## Ссылки для просмотра

**Создать ссылку для просмотра** даёт ссылку, по которой файл может прочитать любой, с входом или без. Редактировать и комментировать по ней нельзя. Новая ссылка отключает старую, а **Выключить** останавливает её сразу.

## Что синхронизируется

- **Изменения документа** сразу же, и файл сохраняется в Redrob Cloud.
- **Указатели и выделение** с именем и цветом каждого участника.
- **Комментарии и версии** для всех, у кого есть доступ.

Нажмите на аватар участника, чтобы следить за его видом; нажмите ещё раз, чтобы перестать.

## Как это устроено

У каждого общего файла свой ключ содержимого, созданный на компьютере, который им поделился. Названия, документ, изменения, указатели, комментарии и версии шифруются этим ключом до того, как покинут компьютер. Redrob Cloud хранит и пересылает только шифротекст.

Сеансы идут через ретранслятор Redrob Cloud, WebSocket в API Redrob Chat. Однорангового соединения и публичного сервера сигнализации нет. Состояние документа хранится в CRDT (Yjs), поэтому одновременные правки объединяются без конфликтов.
